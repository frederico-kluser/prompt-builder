# Changelog

Todas as mudanças notáveis de **prompt-builder** (pacote npm `prompt-builder-cli`) são registadas
neste ficheiro.

O formato baseia-se em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e o projeto segue
[Semantic Versioning](https://semver.org/lang/pt-BR/).

- As versões saem como tags `v<MAJOR>.<MINOR>.<PATCH>` a partir de `main`; as tags `v*` são
  imutáveis (ruleset `.github/rulesets/regras-tags.json`).
- As entradas são **geradas** a partir dos [Commits Convencionais](https://www.conventionalcommits.org/) —
  nunca escritas à mão. O release é cortado pela automação de `.changeset/`
  (`npm run version-packages` + `.github/workflows/publish-npm.yml`).
- Comparação: <https://github.com/frederico-kluser/prompt-builder/compare/>
