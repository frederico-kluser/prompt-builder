Skill de agente: a skill `prompt-builder` passa a dizer onde o projeto está de verdade. O novo `where.sh` da skill, chamado pelo symlink de qualquer agente, segue o link até a pasta real e informa a raiz (checkout do repositório, pacote npm instalado ou cópia do `init`), o comando do CLI que funciona de qualquer diretório (o `prompt-builder` do PATH só quando ele leva a esta instalação), o estado do build, a origem da key (nunca o valor), o diretório de dados e o comando exato que corrige o que faltar. O guia novo `terminal.md` (`prompt-builder skill terminal`) cobre a operação completa pelo terminal: modos, opções recomendadas, MCP, Jev, modo agente e o que fazer em cada código de saída. A skill parte das opções recomendadas (`config example`, `models.md`) e sempre pergunta ao usuário se ele quer sugerir outro modelo antes de gastar. Instaladores: `install-agent-skill.sh` e `agent-setup.sh`, rodados de um worktree git ligado, passam a instalar a partir da cópia principal do repositório — um link global para um worktree quebrava a skill em todos os agentes quando o worktree era removido (`PB_ALLOW_WORKTREE=1` mantém o comportamento antigo).
